## 🌟 Features

- 🧑‍💻 **Admin Panel** – Create, edit, and delete blog posts with ease
- 🧠 **Gemini API Integration** – Auto-generates blog descriptions using Google’s Gemini AI
- 🖼️ **ImageKit** – Fast and optimized image handling for blogs
- 🧵 **Rich Markdown Editor** – Write blogs in Markdown format (customizable)
- 🔒 **Authentication** – Secured login for admin access only
- 📦 **MERN Stack** – MongoDB, Express.js, React.js, Node.js
- 🎨 **Tailwind CSS** – Fully responsive and modern UI design

## 🛠️ Setup Instructions

```bash
# Clone the repo
git clone https://github.com/ashishcodes05/Vistoria.git

# Install dependencies
cd Vistoria
npm install

# Create a .env file and configure:
# - MONGO_URI
# - GEMINI_API_KEY
# - IMAGEKIT_PUBLIC_KEY, IMAGEKIT_PRIVATE_KEY, IMAGEKIT_ENDPOINT

# Start the server
npm run dev
